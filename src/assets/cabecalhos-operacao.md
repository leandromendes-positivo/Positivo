# Imagens dos cabeçalhos

`cabecalhos-operacao.webp` foi criado em 08/10/2026 com geração de imagens para este painel, a pedido do proprietário. São ilustrações fotográficas; não representam instalações reais da Positivo nem dados da operação.

O atlas de 1536 × 1024 contém quatro cenas originais, diferentes das imagens dos indicadores:

- Superior esquerdo: conferência e devolução de componentes.
- Superior direito: ferramentas e estação de atendimento técnico.
- Inferior esquerdo: armazenamento de peças de reposição.
- Inferior direito: análise operacional em uma estação de trabalho.

Cada quadrante tem proporção 3:2. `cabecalhos.css` enquadra cada cena sem distorcer, com um véu transparente por tema. As imagens são decorativas e não contêm informações necessárias à operação. O build incorpora o WebP uma única vez no CSS de cada versão do painel.
