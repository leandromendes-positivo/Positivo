# Imagem do cabeçalho de férias

`ferias-calendario.webp` foi criada por geração de imagem para este projeto e otimizada em WebP, preservando a composição original. É uma fotografia ilustrativa de calendário de mesa; a programação real é exibida pelos componentes da página.

O build incorpora a imagem nos três formatos de HTML. O CSS ajusta enquadramento e contraste para os temas claro e escuro e para telas pequenas.
